# Skills

What [[rpg-dnd-srd-excerpt]] covers about skills:

## Statements

- (A character's starting skill proficiencies are determined at character creation, and a monster's skill proficiencies appear in the monster's stat block.) _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00102))_
- A skill represents a specific aspect of an ability score, and an individual's proficiency in a skill demonstrates a focus on that aspect. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00102))_
- (No skills are related to Constitution.) See an ability's description in the later sections of this section for examples of how to use a skill associated with an ability. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00104))_
- Each ability covers a broad range of capabilities, including skills that a character or a monster can be proficient in. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00102))_
- The skills related to each ability score are shown in the following list. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00104))_
- Without proficiency in the skill, the individual makes a normal ability check. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00106))_
- Each of these aspects of Dexterity has an associated skill: Acrobatics, Sleight of Hand, and Stealth, respectively. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00103))_
- So a character who has proficiency in the Stealth skill is particularly good at Dexterity checks related to sneaking and hiding. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00103))_
- Sometimes, the GM might ask for an ability check using a specific skill-for example, "Make a Wisdom (Perception) check." At other times, a player might ask the GM if proficiency in a particular skill applies to a check. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00106))_
- For example, a Dexterity check might reflect a character's attempt to pull off an acrobatic stunt, to palm an object, or to stay hidden. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00103))_
- If the character lacks that proficiency, he or she just makes a Strength check. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00107))_
- For example, if a character attempts to climb up a dangerous cliff, the GM might ask for a Strength (Athletics) check. _(rpg_dnd_srd_excerpt.pdf (source-range-b7d08967-00107))_
