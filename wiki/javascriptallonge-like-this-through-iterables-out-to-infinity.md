## Key supported claims

- The .iterator() method returns an iterator object for iterable collections. (raw/javascriptallonge.pdf)
- The for...of loop works with any object that has a Symbol.iterator method returning an iterator. (raw/javascriptallonge.pdf)
- Iterables can represent infinitely large collections, but spreading them into arrays causes infinite loops. (raw/javascriptallonge.pdf)
- Spreading iterables creates an array from their elements, which may not be intended. (raw/javascriptallonge.pdf)
- New code is encouraged to use a different method name for returning iterators to avoid conflicts. (raw/javascriptallonge.pdf)
