- JavaScript can emulate this behavior using destructuring to extract return values. (raw/javascriptallonge.pdf p.106-107)
- A function can return a formatted string and a status, like 'Reginald is a programmer' and 'ok', using destructuring. (raw/javascriptallonge.pdf p.106-107)
