## Key supported claims

- const bindings prevent reassignment of names in existing scopes but allow shadowing in new scopes. (raw/javascriptallonge.pdf p.60-61)
- Rebinding a name with const in an existing scope results in an error. (raw/javascriptallonge.pdf p.60-61)
- JavaScript allows rebinds of names bound with parameters by default. (raw/javascriptallonge.pdf p.60-61)
- const bindings simplify program analysis by ensuring values do not change. (raw/javascriptallonge.pdf p.60-61)
