## Key supported claims

- Some iterables can be modelled as state machines, such as the Fibonacci sequence generator. (raw/javascriptallonge.pdf)
- Generators implicitly manage state through linear control flow, while iterators require explicit state tracking. (raw/javascriptallonge.pdf)
- The Fibonacci generator has three states: generating 0, generating 1, and generating subsequent values. (raw/javascriptallonge.pdf)
- Iterators require explicit state representation, such as using a state pattern, to manage multiple states. (raw/javascriptallonge.pdf)
