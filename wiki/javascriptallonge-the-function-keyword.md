## Key supported claims

- The function keyword defines functions with specific rules for magic names like 'this' and 'arguments'. (raw/javascriptallonge.pdf p.74-75)
- The 'this' magic name refers to the function's context, while 'arguments' holds the function's passed arguments. (raw/javascriptallonge.pdf p.74-75)
- The 'arguments' object is not an array but behaves like one, with properties named like integers. (raw/javascriptallonge.pdf p.74-75)
- The 'arguments' object is used in recipes like partial application and ellipses. (raw/javascriptallonge.pdf p.74-75)
