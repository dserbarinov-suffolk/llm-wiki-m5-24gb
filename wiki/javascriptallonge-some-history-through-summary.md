## Key supported claims

- Linked lists in Lisp are faster for extracting elements except the head compared to arrays. (raw/javascriptallonge.pdf)
- Arrays in JavaScript pessimistically copy references when extracting elements, which can be inefficient. (raw/javascriptallonge.pdf)
- Lisp's cons cells represent lists as linked lists with head and tail pointers. (raw/javascriptallonge.pdf)
- Lisp's cons cells store two 15-bit values in one word. (raw/javascriptallonge.pdf)
- Using tail calls to map and fold over arrays with [first, ...rest] is not the recommended approach. (raw/javascriptallonge.pdf)
