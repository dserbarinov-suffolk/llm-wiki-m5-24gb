# value types

Source: [[javascriptallonge]]

## Statements

- This is the case with the strings, numbers, and booleans we have seen so far. (javascriptallonge.pdf p.22)
- If they are the same kind of cup, and they hold the same contents, we have no way to tell the difference between them. (javascriptallonge.pdf p.22)
- Third, some types of cups have no distinguishing marks on them. (javascriptallonge.pdf p.22)
- We'll use both terms interchangeably. (javascriptallonge.pdf p.22)
- Note well what is happening with these examples: Even when we obtain a string, number, or boolean as the result of evaluating an expression, it is identical to another value of the same type with the same 'content.' Strings, numbers, and booleans are examples of what JavaScript calls 'value' or 'primitive' types. (javascriptallonge.pdf p.22)
