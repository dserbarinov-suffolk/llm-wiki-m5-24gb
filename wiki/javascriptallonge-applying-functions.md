# applying functions

Source: [[javascriptallonge]]

## Statements

- The way we use functions is to apply them to zero or more values called arguments . (javascriptallonge.pdf p.31)
- We'll put it in parentheses 17 to keep the parser happy, like we did above: (() => 0) . (javascriptallonge.pdf p.31)
- 17 If you're used to other programming languages, you've probably internalized the idea that sometimes parentheses are used to group operations in an expression like math, and sometimes to apply a function to arguments. (javascriptallonge.pdf p.31)
