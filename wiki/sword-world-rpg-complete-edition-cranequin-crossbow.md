# Cranequin Crossbow

Source: [[sword-world-rpg-complete-edition]]

## Statements

- However, it takes time to wind up, so there are significant restrictions on continuous firing. (Sword World RPG - Complete Edition.pdf p.270)
- A hoist is attached to a crossbow so that the string can be tightened strongly with a small amount of force. (Sword World RPG - Complete Edition.pdf p.270)

## Technical atoms

<a id="atom-1"></a>
**Atom:** rule

```
If you've tightened the strings and prepared them in advance, you can fire the first shot immediately , but after that, you'll only be able to fire once every four rounds.
```
