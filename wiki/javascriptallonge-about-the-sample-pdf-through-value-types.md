## Key supported claims

- Strings, numbers, and booleans are value types in JavaScript with identical content when they match. (raw/javascriptallonge.pdf p.22-22)
- Some value types lack distinguishing marks, making them indistinguishable if they share the same content and type. (raw/javascriptallonge.pdf p.22-22)
- Even with identical content and type, two cups (values) can still be distinguished. (raw/javascriptallonge.pdf p.22-22)
