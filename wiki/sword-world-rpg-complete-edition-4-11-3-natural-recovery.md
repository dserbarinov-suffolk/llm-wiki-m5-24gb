# 4.11.3 Natural Recovery

Source: [[sword-world-rpg-complete-edition]]

## Statements

- If a character is conscious and at rest (full rest in a safe place), that character recovers 1 point of life force per day. (Sword World RPG - Complete Edition.pdf p.54)
- If a character is not at rest (e.g., traveling, fighting monsters in a labyrinth, not getting much sleep at night due to keeping watch), that character cannot recover any life force at all. (Sword World RPG - Complete Edition.pdf p.54)

## Technical atoms

<a id="atom-1"></a>
**Atom:** rule

```
If someone with the healer skill is nursing them, that character can recover even more life force each day.
```
