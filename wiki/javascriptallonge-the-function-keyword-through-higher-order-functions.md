## Key supported claims

- The function keyword is used to define named functions in JavaScript, requiring the return keyword to return values from the function body. (raw/javascriptallonge.pdf)
- Function declarations are hoisted to the top of the function in which they occur, allowing them to be used before their definition. (raw/javascriptallonge.pdf)
- A function declaration cannot exist inside of any expression, making it distinct from a function expression. (raw/javascriptallonge.pdf)
- JavaScript functions are values, allowing them to take functions as arguments, return functions, or both. (raw/javascriptallonge.pdf)
- A higher-order function is one that takes functions as arguments, returns functions, or both, such as the repeat function. (raw/javascriptallonge.pdf)
