## Key supported claims

- The function keyword in JavaScript is used to declare named functions, which differ from arrow functions by requiring a block and return keyword for outputs. (raw/javascriptallonge.pdf)
- Function declarations are hoisted to the top of their containing function, but declaring functions inside blocks is technically illegal and may behave unpredictably in production. (raw/javascriptallonge.pdf)
- A higher-order function is one that takes functions as arguments, returns functions, or both, exemplified by JavaScript's repeat function. (raw/javascriptallonge.pdf)
