## Statements

- By casting this spell, the caster will be able to converse in a language previously unknown to them. This spell only allows you to speak one language each time you cast it, so in order to be able to speak two or three unknown languages at the same time, you must expand the effect of the spell. Also, this spell only allows you to use languages used by intelligent creatures listed on Table 12-1: Languages (see p. 159), so that means you will not be able to speak to animals, etc. _(Sword World RPG - Complete Edition.pdf (source-range-e5870dca-02160))_
