## Key supported claims

- Function declarations are hoisted to the top of their enclosing scope, allowing them to be used before their definition in the code. (raw/javascriptallonge.pdf p.65-66)
- This behavior is intentionally designed in JavaScript to support a programming style where main logic is placed upfront, and helper functions are defined later. (raw/javascriptallonge.pdf p.65-66)
- There is an alternative syntax for naming and defining functions, which behaves similarly to const bindings but with distinct differences. (raw/javascriptallonge.pdf p.65-66)
