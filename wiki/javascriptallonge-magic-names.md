# Magic Names

Source: [[javascriptallonge]]

## Statements

- What we haven't discussed so far is that JavaScript also binds values to some 'magic' names in addition to any you put in the argument list. (javascriptallonge.pdf p.74)
- When a function is applied to arguments (or 'called'), JavaScript binds the values of arguments to the function's argument names in an environment created for the function's execution. (javascriptallonge.pdf p.74)
