## Key supported claims

- Function declarations cannot exist inside expressions, as they are considered function expressions instead. (raw/javascriptallonge.pdf)
- JavaScript functions can take functions as arguments, return functions, or both, making them higher-order functions. (raw/javascriptallonge.pdf)
- JavaScript functions take values as arguments and return values, forming the basis of higher-order functions. (raw/javascriptallonge.pdf)
