## Key supported claims

- A POJO can be used to create a map from positions to moves in a game of naughts and crosses. (raw/javascriptallonge.pdf)
- A stateless function can be used to play naughts and crosses, but it pushes the responsibility of tracking the game state onto the player. (raw/javascriptallonge.pdf)
- Interactive generators can be used to play naughts and crosses, but the first call to .next() must be without any arguments. (raw/javascriptallonge.pdf)
- Generators can be used to implicitly manage the state of a game, similar to how state is managed in a lookup table. (raw/javascriptallonge.pdf)
