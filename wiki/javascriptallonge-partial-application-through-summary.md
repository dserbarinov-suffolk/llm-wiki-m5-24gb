## Key supported claims

- Modern JavaScript implementations provide a map method for arrays, but Underscore's implementation also works with older browsers if you are working with that headache. (raw/javascriptallonge.pdf)
- JavaScript binds values to 'magic' names like 'this' and 'arguments' in addition to any you put in the argument list. (raw/javascriptallonge.pdf)
- Functions defined with the function keyword and fat arrows have different semantics for magic names, with fat arrows acquiring bindings from their enclosing scope. (raw/javascriptallonge.pdf)
- There are two separate rules for 'magic' names, one for functions defined with the function keyword and another for functions defined with 'fat arrows.' (raw/javascriptallonge.pdf)
