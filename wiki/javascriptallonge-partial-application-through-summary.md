## Key supported claims

- Partial application is a technique where a function is applied to some, but not all, of its arguments, resulting in a new function that represents part of the application. (raw/javascriptallonge.pdf)
- JavaScript binds values to 'magic' names like 'this' and 'arguments' in addition to any explicit arguments provided in the function definition. (raw/javascriptallonge.pdf)
- The behavior of 'magic' names differs between functions defined with the 'function' keyword and those defined with 'fat arrows,' with the latter acquiring bindings from the enclosing scope. (raw/javascriptallonge.pdf)
