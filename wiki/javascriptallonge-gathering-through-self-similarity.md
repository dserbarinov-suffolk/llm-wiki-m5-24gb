## Key supported claims

- The ... notation in JavaScript does not provide universal pattern-matching capability, often coercing values or passing undefined around. (raw/javascriptallonge.pdf)
- Destructuring can be used to emulate multiple return values, such as returning a value and an error code. (raw/javascriptallonge.pdf)
- Gathering in parameters is referred to as 'rest parameters,' and it allows functions to accept a variable number of arguments. (raw/javascriptallonge.pdf)
- The technique does not work for arrays containing undefined values, though this is not demonstrated in the examples provided. (raw/javascriptallonge.pdf)
