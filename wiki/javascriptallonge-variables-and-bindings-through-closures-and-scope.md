## Key supported claims

- JavaScript and related languages handle variable access in nested functions by referencing variables from the outer scope. (raw/javascriptallonge.pdf p.44-44)
- A function's environment includes variables from the outer scope, such as x, which is referenced inside the nested function. (raw/javascriptallonge.pdf p.44-44)
- The result of applying a function is another function value, which captures the environment at the time of creation. (raw/javascriptallonge.pdf p.44-44)
