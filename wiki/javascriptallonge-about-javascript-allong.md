# About JavaScript Allongé

Source: [[javascriptallonge]]

## Statements

- It's written in JavaScript, because JavaScript hits the perfect sweet spot of being both widely used, and of having proper first-class functions with lexical scope. (javascriptallonge.pdf p.7)
- JavaScript Allongé is a first and foremost, a book about programming with functions . (javascriptallonge.pdf p.7)
- JavaScript Allongé begins at the beginning, with values and expressions, and builds from there to discuss types, identity, functions, closures, scopes, collections, iterators, and many more subjects up to working with classes and instances. (javascriptallonge.pdf p.7)
- JavaScript idioms like function combinators and decorators leverage JavaScript's power to make code easier to read, modify, debug and refactor. (javascriptallonge.pdf p.7)
- It also provides recipes for using functions to write software that is simpler, cleaner, and less complicated than alternative approaches that are object-centric or code-centric. (javascriptallonge.pdf p.7)
