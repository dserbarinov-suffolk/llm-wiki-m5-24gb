## Key supported claims

- JavaScript uses truthiness, where values like false, null, undefined, NaN, 0, and '' are falsy, while others are truthy. (raw/javascriptallonge.pdf)
- The && and || operators act as control-flow tools with short-cut semantics, evaluating only necessary expressions. (raw/javascriptallonge.pdf)
- Function parameters in JavaScript are eagerly evaluated, unlike control-flow operators, which can lead to infinite recursion if not handled carefully. (raw/javascriptallonge.pdf)
