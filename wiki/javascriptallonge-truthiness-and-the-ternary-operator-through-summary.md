## Key supported claims

- JavaScript inherited the ternary operator from the C family of languages, which is a control-flow operator. (raw/javascriptallonge.pdf)
- The logical operators && and || in JavaScript are best thought of as control-flow operators, not strict boolean logical operators. (raw/javascriptallonge.pdf)
- The ternary operator (?:), ||, and && are control-flow operators with shortcut semantics, not always returning true or false. (raw/javascriptallonge.pdf)
- To implement control-flow semantics in functions, JavaScript allows passing anonymous functions instead of expressions. (raw/javascriptallonge.pdf)
