## Key supported claims

- Logical operators && and || in JavaScript function as control-flow operators rather than strict logical operators. (raw/javascriptallonge.pdf)
- Function parameters in JavaScript are eagerly evaluated, which can lead to infinite recursion if not handled carefully. (raw/javascriptallonge.pdf)
- && returns the left-hand expression if it is falsy, without evaluating the right-hand expression. (raw/javascriptallonge.pdf)
