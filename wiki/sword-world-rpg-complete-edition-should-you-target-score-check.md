# Should You Target Score Check

What [[sword-world-rpg-complete-edition]] covers about should you target score check:

## Statements

### Chapter 9: / Setting Target Scores and Difficulties / Should You Use a Target Score Check or a Difficulty Check?

- There are two types of success rolls: those that use a target score for the check and those that use a difficulty for the check. The game master must decide which of these should be used to make the success roll. _(Sword World RPG - Complete Edition.pdf (source-range-e5870dca-04530))_

- The standard for deciding is whether the character can tell if the action succeeded or failed . For example, if you want to jump over a cliff, success or failure is clear. If you succeed, you can jump over it, and if you fail, you will fall. Checks for actions with clear successes or failures are made using target scores . _(Sword World RPG - Complete Edition.pdf (source-range-e5870dca-04531))_

- These actions result in a difficulty check . If you can fail on a success roll but still have it appear to be a success, then the success roll should be made as a difficulty check. _(Sword World RPG - Complete Edition.pdf (source-range-e5870dca-04533))_

### Chapter 9: / Setting Target Scores and Difficulties / Should You Use a Target Score Check or a Difficulty Check? / 10.1 NPC and Monster Action Announcement / Combat in Special Situations / 10.5 Attacks Against the Sleeping / Rules for Sleeping Adventurers

- If a sleeping adventurer is approached by a monster, the baseline score is adventurer level + intelligence bonus , and if you succeed on a resistance roll against target score 9, you can wake up before being attacked. If the monster has the ability to sneak up on you, the target score will be even higher. If they approach using stealthy step , etc. their final score will become the target score. _(Sword World RPG - Complete Edition.pdf (source-range-e5870dca-04632))_

> If you attack a sleeping monster but do not deal any damage, or if you deal damage but are unable to reduce its life points to 0, the monster will wake up immediately. It will probably become angry and counterattack the adventurer starting on the next round.
