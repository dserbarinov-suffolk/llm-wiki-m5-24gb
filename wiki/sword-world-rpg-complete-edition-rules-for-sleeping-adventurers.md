# Rules for Sleeping Adventurers

Source: [[sword-world-rpg-complete-edition]]

## Statements

- If the monster has the ability to sneak up on you, the target score will be even higher. (Sword World RPG - Complete Edition.pdf p.139)
- their final score will become the target score. (Sword World RPG - Complete Edition.pdf p.139)
- attacks a sleeping adventurer, the attack will automatically hit. (Sword World RPG - Complete Edition.pdf p.140)
- If the attack does not reduce life to 0, the adventurer wakes up immediately. (Sword World RPG - Complete Edition.pdf p.140)
- Therefore, the quickest way to wake up your friends is to kick them. (Sword World RPG - Complete Edition.pdf p.140)

## Technical atoms

<a id="atom-1"></a>
**Atom:** rule

```
If a sleeping adventurer is approached by a monster, the baseline score is adventurer level + intelligence bonus , and if you succeed on a resistance roll against target score 9, you can wake up before being attacked.
```

<a id="atom-2"></a>
**Atom:** rule

```
If you're put to sleep by magical means such as Sleep Cloud , you must make a check via mental power resistance roll each round as long as combat continues.
```
