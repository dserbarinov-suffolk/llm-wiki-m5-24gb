### Values and Expressions over Coffee

All values are expressions. For example, the number `42` is both an expression and a value. When you type it into JavaScript, you get the same thing back. Similarly, strings like "JavaScript" + " " + "Allonge" evaluate to "JavaScript Allonge".

### Values and Identity

In JavaScript, we test whether two values are identical using the === operator. For instance:

- `2 === 2` returns `true`
- `'hello' !== 'goodbye'` returns `true`

The === operator checks both type and content. If the types differ (e.g., string vs. number), the result is `false`. If the types are the same but contents differ, the result is also `false`.
