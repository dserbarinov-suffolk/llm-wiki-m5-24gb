## Key supported claims

- mapWith wraps map to turn any function into a mapper, reversing arguments and currying the function. (raw/javascriptallonge.pdf p.193-194)
- Passing a function to mapWith returns a function that applies the mapping to any array. (raw/javascriptallonge.pdf p.193-194)
- mapWith can be used similarly to callRight with map for the same result. (raw/javascriptallonge.pdf p.193-194)
- Both mapWith and callRight with map achieve the same destination of composing functions from common pieces. (raw/javascriptallonge.pdf p.193-194)
