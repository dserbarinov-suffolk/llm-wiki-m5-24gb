## Key supported claims

- Generator functions yield values instead of returning a single value, and JavaScript creates an iterator object with a .next() method for iteration. (raw/javascriptallonge.pdf p.234-236)
- Calling a generator function multiple times produces new iterators, each starting from the beginning. (raw/javascriptallonge.pdf p.234-236)
- Generator methods can be used to define iterable objects, enabling for...of loops and spread operators. (raw/javascriptallonge.pdf p.234-236)
