# Attack Modifiers

What [[rpg-cairn-2e-core]] covers about attack modifiers:

## Statements

### Attack Modifiers

- Attacks with the Blast quality affect all targets in the noted area, rolling separately for each affected character. This can be anything from explosions to a dragon's breath or the impact of a meteorite. If unsure how many targets can be affected, roll the related damage die for a result . _(rpg_cairn_2e_core.pdf (source-range-ad2c341f-00217))_
