## Key supported claims

- Mutation is a complex subject, with some languages avoiding it entirely while others use it for efficiency. (raw/javascriptallonge.pdf)
- A common pattern is to allow mutation during data construction but avoid it during consumption for clarity. (raw/javascriptallonge.pdf)
- Shadowing a const with a let does not permit it to be rebound in its original scope. (raw/javascriptallonge.pdf)
- Using let to bind a variable within a block does not change the outer binding, similar to const. (raw/javascriptallonge.pdf)
