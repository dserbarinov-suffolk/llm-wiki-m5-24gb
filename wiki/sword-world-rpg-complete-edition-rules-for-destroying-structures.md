# Rules for Destroying Structures

Source: [[sword-world-rpg-complete-edition]]

## Statements

- Basically, characters cannot destroy walls or doors, but if you really want to implement something like this, it's fine for the game master to make decisions using his or her own common sense ('You have an ax, so you should be able to break down a wooden door'). (Sword World RPG - Complete Edition.pdf p.277)
- However, if you specifically want to handle this numerically, please use the following rules. (Sword World RPG - Complete Edition.pdf p.277)
