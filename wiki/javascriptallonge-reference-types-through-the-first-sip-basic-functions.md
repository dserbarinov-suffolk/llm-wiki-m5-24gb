## Key supported claims

- Arrays like [1, 2, 3] are generated as unique instances even if they have identical contents. (raw/javascriptallonge.pdf p.22-23)
- [] can be combined with expressions to generate arrays dynamically. (raw/javascriptallonge.pdf p.22-23)
- Arrays with the same contents are not considered identical in JavaScript. (raw/javascriptallonge.pdf p.22-23)
- An array looks like this: [1, 2, 3]. (raw/javascriptallonge.pdf p.22-23)
- This is true of many other kinds of values, including functions. (raw/javascriptallonge.pdf p.22-23)
