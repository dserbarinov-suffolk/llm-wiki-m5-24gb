## Key supported claims

- Destructuring in JavaScript does not function as pattern matching, as it binds undefined to names when no values are available. (raw/javascriptallonge.pdf p.105-106)
- JavaScript often requires custom code to detect failure conditions, as it cannot rely on the language to point out semantically meaningless operations. (raw/javascriptallonge.pdf p.105-106)
- JavaScript has historically avoided catastrophic errors by coercing values or passing undefined around to keep execution going. (raw/javascriptallonge.pdf p.105-106)
- JavaScript's design has striven to avoid catastrophic errors since its inception, often through value coercion or handling of undefined. (raw/javascriptallonge.pdf p.105-106)
- Destructuring assignments with ... can handle missing items by assigning empty arrays or undefined values. (raw/javascriptallonge.pdf p.105-106)
