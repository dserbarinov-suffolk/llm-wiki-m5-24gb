## Key supported claims

- Unary is a function decorator that transforms any function into one taking exactly one argument. (raw/javascriptallonge.pdf p.82-83)
- JavaScript's map function calls each function with three arguments: the element, its index, and the array itself. (raw/javascriptallonge.pdf p.82-83)
- If a function only takes one argument, the additional arguments are ignored. (raw/javascriptallonge.pdf p.82-83)
- Unary can be used to convert parseInt into a function taking only one argument. (raw/javascriptallonge.pdf p.82-83)
- Unary can be applied to write ['1', '2', '3'].map((s) => parseInt(s)) or use a decorator to do the job. (raw/javascriptallonge.pdf p.82-83)
