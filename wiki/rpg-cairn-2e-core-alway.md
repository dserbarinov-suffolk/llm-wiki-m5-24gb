## Statements

### Core Rules / Combat / Retreat

- Running away from a dire situation always requires a successful DEX save, as well as a safe destination to run to. _(rpg_cairn_2e_core.pdf (source-range-9b4fff26-00231))_

### Procedures / Downtime Actions / Research

- As always, the question must come from an experience that occurred during play. _(rpg_cairn_2e_core.pdf (source-range-9b4fff26-00403))_

### Saves / Save Principles

- Always provide multiple viable options for the PCs to choose from. The more choices, the more interesting the situation becomes. _(rpg_cairn_2e_core.pdf (source-range-9b4fff26-00507))_
