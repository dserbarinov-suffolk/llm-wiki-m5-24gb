## Key supported claims

- Iterator objects allow iteration mechanics to be factored using the same tools as other objects in the system. (raw/javascriptallonge.pdf)
- Iterables can represent infinitely large collections, but spreading them into arrays leads to infinite loops. (raw/javascriptallonge.pdf)
- An ordered collection guarantees elements are iterated in order from the beginning each time. (raw/javascriptallonge.pdf)
- Iterating over a collection using its iterator can be more efficient than spreading the collection. (raw/javascriptallonge.pdf)
- A stack example demonstrates how to sum values using an iterator. (raw/javascriptallonge.pdf)
