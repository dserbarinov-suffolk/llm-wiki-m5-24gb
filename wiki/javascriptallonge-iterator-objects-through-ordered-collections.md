## Key supported claims

- Iterator objects allow iteration mechanics to be factored using the same tools as other objects in the system. (raw/javascriptallonge.pdf)
- The .iterator() method returns an iterator object. (raw/javascriptallonge.pdf)
- Spreading iterables creates an array from the iterable's elements. (raw/javascriptallonge.pdf)
- Iterables needn't represent ordered collections. (raw/javascriptallonge.pdf)
- Iterables can represent infinitely large collections, but spreading them into arrays can lead to infinite loops. (raw/javascriptallonge.pdf)
