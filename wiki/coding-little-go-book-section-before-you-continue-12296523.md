## Statements

- If you're new to the world of concurrent programming, it might all seem rather overwhelming. _(coding_little_go_book.pdf (source-range-810ce361-00467))_
- Go aims to make it easier. _(coding_little_go_book.pdf (source-range-810ce361-00467))_
- Goroutines effectively abstract what's needed to run concurrent code. _(coding_little_go_book.pdf (source-range-810ce361-00468))_
- Having said that, I still make extensive use of the various synchronization primitives found in the sync and sync/atomic packages. _(coding_little_go_book.pdf (source-range-810ce361-00469))_
- I encourage you to first focus on channels, but when you see a simple example that needs a short-lived lock, consider using a mutex or readwrite mutex. _(coding_little_go_book.pdf (source-range-810ce361-00469))_
