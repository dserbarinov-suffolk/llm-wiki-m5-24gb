## Key supported claims

- Function decorators are higher-order functions that take one function as an argument and return another function that is a variation of the original. (raw/javascriptallonge.pdf p.69-70)
- Function decorators allow more flexibility compared to combinators by not requiring strict purity. (raw/javascriptallonge.pdf p.69-70)
- The 'not' function serves as a decorator that modifies a function while maintaining its original semantics. (raw/javascriptallonge.pdf p.69-70)
- The B Combinator implementation is correct in Scheme but needs adjustments for general-purpose JavaScript use. (raw/javascriptallonge.pdf p.69-70)
- Other decorators like 'once' and 'maybe' are mentioned as examples in the text. (raw/javascriptallonge.pdf p.69-70)
