## Key supported claims

- ECMAScript 6 introduces three major groups of features: improved syntax for existing features, new standard library functionality, and completely new features. (raw/javascriptallonge.pdf p.13-13)
- Better syntax for existing features includes classes and modules. (raw/javascriptallonge.pdf p.13-13)
- New standard library functionality includes promises, maps, sets, and new methods for strings and arrays. (raw/javascriptallonge.pdf p.13-13)
- Completely new features include generators, proxies, and WeakMaps. (raw/javascriptallonge.pdf p.13-13)
